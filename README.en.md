# skillgen · Agent Skill Template Generator

A zero-dependency Node.js CLI that generates clear, editable `SKILL.md` projects. It supports interactive and non-interactive workflows with Chinese, English, and bilingual templates.

[中文 README](README.md) · [Report an issue](https://github.com/qyp1a/skillgen/issues) · [Contributing](CONTRIBUTING.md)

## Features

- **Zero runtime dependencies:** built entirely with Node.js built-ins.
- **Four template types:** basic skills, CLI tools, multi-step workflows, and MCP connections.
- **Bilingual:** the CLI and templates support `zh`, `en`, and `both`.
- **Safe YAML frontmatter:** quotes, backslashes, and other characters are escaped correctly.
- **Lean by default:** required skill and publishing files are generated by default; example code is opt-in.
- **Automation-friendly:** all generation options are available as CLI flags.

## Quick start

Run without installing:

```bash
npx skillgen
```

Install globally:

```bash
npm install --global skillgen
skillgen
```

Run from source:

```bash
git clone https://github.com/qyp1a/skillgen.git
cd skillgen
npm test
node cli.js
```

Node.js 18 or later is required.

## Non-interactive usage

```bash
npx skillgen \
  --name report-workflow \
  --type workflow \
  --lang both \
  --desc "当用户需要生成或校验报表时使用" \
  --desc-en "Use when the user needs to generate or validate reports" \
  --author "Your Name" \
  --yes
```

Common options:

| Option | Description |
| --- | --- |
| `--name` | Skill name of up to 64 lowercase letters, digits, and hyphens |
| `--type` | `basic`, `cli`, `workflow`, or `mcp` |
| `--lang` | `zh`, `en`, or `both` |
| `--desc` | Chinese or primary description |
| `--desc-en` | English description; combined with `--desc` in `both` mode |
| `--author` | Author used in the generated README and LICENSE |
| `--examples` | Also generate `scripts/example.js` |
| `--force` | Write into an existing directory and overwrite generated files with matching names; other files are preserved |
| `--yes` | Skip prompts and use defaults |
| `--ui` | CLI interface language: `zh` or `en` |
| `--list-types` | List template types |
| `--version` / `--help` | Show version or help |

## Template types

| Type | Use case | Focus |
| --- | --- | --- |
| `basic` | General knowledge or process | Triggers, steps, examples, troubleshooting |
| `cli` | Command-line tool wrapper | Prerequisites, command reference, output and failure handling |
| `workflow` | Multi-stage pipeline | Stage inputs and outputs, quality gates, recovery |
| `mcp` | MCP server usage guide | Server setup, tool inventory, call patterns, errors |

## Complete examples

[`examples/skills/`](examples/README.md) contains six finished skills covering GitHub release preparation, bilingual README synchronization, Node CLI regression testing, skill quality review, changelog drafting, and npm release checks. They live outside `.agents/skills/`, so cloning the repository does not activate them automatically.

## Generated output

Default structure:

```text
report-workflow/
├── SKILL.md
├── README.md
└── LICENSE
```

With `--examples`, skillgen also creates `scripts/example.js`. Directories such as `scripts/`, `references/`, and `assets/`, plus `agents/openai.yaml`, are optional resources and should be added only when the skill needs them.

## Use with Codex

- Repository-scoped skill: place it under `.agents/skills/<skill-name>/` in the repository.
- User-scoped skill: place it under `$HOME/.agents/skills/<skill-name>/`.
- To install a skill from GitHub for personal use, invoke `$skill-installer` in Codex and provide the repository URL.
- For installable distribution to other users, OpenAI currently recommends packaging skills as plugins.

Other Agent Skills hosts may scan different locations; follow the documentation for the target host.

See the [official OpenAI Build skills documentation](https://learn.chatgpt.com/docs/build-skills) and the [Agent Skills specification](https://agentskills.io/specification).
