# Security Policy

## Supported versions

Until the project reaches a stable release, security fixes are applied to the latest published version only.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository:

https://github.com/qyp1a/skillgen/security/advisories/new

Do not open a public issue for a vulnerability before a fix is available. Include the affected version, reproduction steps, expected impact, and any suggested mitigation.
