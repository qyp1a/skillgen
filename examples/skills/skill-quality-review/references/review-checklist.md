# Skill quality review checklist

Hard requirements (all must hold):

- [ ] Name is 64 characters or fewer, lowercase letters/digits/hyphens.
- [ ] Description is present, one to two sentences, states when to use.
- [ ] No leftover template placeholders (`{{...}}`, `TODO`, `TBD`).
- [ ] Every file referenced by the skill exists.

Recommendations:

- [ ] Concrete trigger examples in "When to Use".
- [ ] At least one realistic example.
- [ ] Troubleshooting table for common failures.
